# 隐私说明

**一句话：数据都在你自己的设备上。没有账号，没有云服务器，没有统计，没有广告。作者收不到你的任何数据。**

## 存了什么，存在哪

**电脑上的 Edge（只在当前 Edge 用户资料里）**

- IndexedDB 数据库 `valrecall`：学习条目、截图、复习记录、笔记、待办和完成记录、奖励记录、草稿，以及同步用的版本记录。
- 捕获时保存：页面地址和标题、视频时间、能读到的作者、视频简介和章节信息、当前时间附近的字幕、当前标签页可见画面的截图。
- `chrome.storage.local` 只存小设置：

| 键                                                    | 内容                               |
| ----------------------------------------------------- | ---------------------------------- |
| `valrecall.preferences`                               | 常规设置                           |
| `valrecall.typography`                                | 字体和字号                         |
| `valrecall.reminderState`、`valrecall.dailyPlanState` | 提醒状态                           |
| `valrecall.workingCard`                               | “工作中”卡片的状态                 |
| `valrecall.rewards`                                   | 是否显示奖励。关着时，账本照常记录 |
| `valrecall.lastBackupAt`                              | 上次导出日期                       |
| `valrecall.persistAsked`                              | 是否已申请持久存储                 |
| `valrecall.savedItemOnce`                             | 是否保存过第一条                   |
| `sync.enabled.v1`                                     | 手机同步开关                       |
| `valrecall.allowance`                                 | 旧版奖励数据，只用来迁移           |

卸载扩展会删除这些数据。也可以在“设置”的“备份与恢复”里删除学习内容：回忆题、截图、草稿、分类、待办和笔记会被删除。如果配对了手机，配对也会失效，要重新配对。有些记录会留在这个浏览器里：奖励账本、部分复习记录、保存和同步记录、待办修改记录。这些记录也会进入之后导出的备份。设置也会留下，但不进备份。要全部删除，只能卸载扩展。

导出的备份文件是普通文件，含有你的学习内容，不含配对密钥。请自己保管好。页面上的“上次导出”只记下你点导出的日期。扩展不知道文件是否真的存好，所以请自己确认。

## 扩展的权限

| 权限                                    | 用途                                     |
| --------------------------------------- | ---------------------------------------- |
| `activeTab`                             | 你按下快捷键时，截取当前标签页的可见画面 |
| `scripting`                             | 捕获或跳转时向视频页注入脚本             |
| `storage`                               | 保存上面的小设置                         |
| `sidePanel`                             | 显示侧边栏                               |
| `alarms`、`notifications`               | 按你的设置提醒复习和每日计划             |
| B 站、YouTube、抖音的视频页（网站权限） | 只在这些页面上捕获                       |
| `nativeMessaging`（可选）               | 手机同步。只有你打开同步时才申请         |

内容脚本会在这些视频页加载，但只是等待。你主动捕获（比如按快捷键）时，它才读取页面。从 ValRecall 打开保存的视频时，它会帮你跳到保存的时间。扩展不看其他网站，不录音，不下载视频，不读剪贴板。

## 网络请求

扩展自己不连接任何服务器，只有一个例外：

**捕获 B 站视频时，读取字幕文件。** 请求从视频页内发出，只发给 `aisubtitle.hdslb.com`、`i0.hdslb.com`、`i1.hdslb.com`、`i2.hdslb.com` 这些 B 站字幕地址，路径只能是 `/bfs/ai_subtitle/` 或 `/bfs/subtitle/`。只用 HTTPS，不跟随跳转，不带 B 站登录信息，3 秒超时。下载的只有字幕，你的数据不会发出去。

点“打开原视频”时，你会像平常一样访问原网站。

## 同步助手（可选，默认没有）

只有你自己构建并安装 Windows 同步助手，在设置里打开同步，下面这些才会发生。

- 助手由 Edge 启动，Edge 关闭后它也停止。它不是 Windows 服务。
- 它在 Wi-Fi 或以太网的私有地址（192.168 等）上监听 TCP 端口 **19284**，用 HTTPS。手机用配对时扫到的证书指纹确认电脑身份。
- 它在同一端口监听 UDP，用来在局域网里被手机发现。手机广播的消息只含一个服务器 ID，回复也只有这个 ID 和端口，不含密钥和数据。只回应同一私有子网的设备。
- 同步内容只有待办和奖励记录。不传学习条目、截图和复习记录。
- 密钥和证书用 Windows DPAPI 加密，存在 `%LOCALAPPDATA%\ValRecall\Sync`。程序在 `%LOCALAPPDATA%\ValRecall\Sync\Host`。
- 安装时只写当前用户的注册表项，名称是 `com.valrecall.sync`，并只允许本扩展连接。
- 默认不改防火墙。只有加上 `-AllowPrivateLanFirewall` 才添加规则，只放行助手程序、专用网络和本地子网。

## 手机 App（可选，要自己构建）

| 权限                                    | 用途                     |
| --------------------------------------- | ------------------------ |
| 相机 `CAMERA`                           | 只在扫配对二维码时打开   |
| 本地网络 `ACCESS_LOCAL_NETWORK`         | 在局域网里找到并连接电脑 |
| 网络 `INTERNET`、`ACCESS_NETWORK_STATE` | 连接电脑，判断是否联网   |

App 只连接已配对电脑的私有地址，不连接互联网上的服务器，也不允许明文网络请求。待办和奖励账本存在 App 内部。这个版本的手机界面不显示账本，但同步时一样会存下来。配对凭据用 Android Keystore 加密。系统云备份已关闭。卸载 App 会删除手机上的这些数据。

## 没有的东西

没有统计和遥测，没有崩溃上报，没有广告，没有账号，不调用远程 AI。
